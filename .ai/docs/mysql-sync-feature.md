## 六、MySQL 现场准备清单

> 以下为每台 MySQL 实例的一次性操作，部署前需完成。

| 操作 | 完成 | 备注 |
|------|:----:|------|
| 开启 binlog（ROW 格式、FULL 行镜像） | | `binlog_format=ROW`, `binlog_row_image=FULL` |
| 每台实例设置唯一 `server-id` | | |
| 创建同步账号 `sync_user`（REPLICATION SLAVE + 库表读写权限） | | 无需 SUPER 权限 |
| 各库建防循环标记表 `_sync_origin` | | DDL 见设计文档第十章 |
